v0.2.372 goombaUterus [feat. > active commands; patch > Usage layouts]

commands:
The last command you send now stays active: plain messages keep its rules, the prompt bar shows it, and the model knows it is still active. The model can ask to switch commands (for example from /spit to /imp), but nothing switches unless you pick Switch in the form, and it only proposes commands marked "suggest: true".

Several commands in one message now run in order, one turn each, instead of being merged. A later command with no text asks for a prompt when its turn comes, unless it is marked "whenBlank: send". Multi-step submissions queue all at once and keep Enter and Alt+Enter in press order, and editing or cancelling a blank queued command closes its question and lets the queue continue.

sidebar:
The Usage block has two layouts, switched with Layout in the Usage menu: grouped (default) shows each account's renewal on its name line and one bar line per window; table shows one line per account under 5h / week / renew columns. Usage turns yellow at 80% and red at 95%, renewals turn yellow within 3 days, and stale numbers are dimmed instead of marked with "*". Sidebar settings now live in sidebar.json in oc's config folder (old openSidebar settings are copied over once), a project's own .config/openSidebar.json no longer overrides them, and Reset global script settings really restores the defaults.

Claude Code:
Skills now load in commands that limit tools, such as /spit. An agent or command that denies skills or the shell also turns off Claude Code's own Skill, Monitor, and TaskStop, and tool-limited commands that allow the shell let Claude watch and stop its background jobs. Warm-ups now list and send for the main ~/.claude login on the Mac, and the Times dialog accepts up to 24 times per day instead of 4.

push commands:
A commit-and-push command can set "pushSession: true" in its frontmatter; oc no longer looks for a command named agent-push. The palette entry is now Push session auto-delete (/pushAutoDelete) and keeps your saved choice.

revive:
Restarting after a rebuild is about 2 seconds faster again on macOS: oc no longer pre-launches occ and native opencode while the server starts.

background shell:
The bgRun entry is gone from the oc menu; background commands use the same approval as any other shell command.

docs:
The README, wiki, and repo docs were checked against the current code, finished plan files were removed, and the docs now say oc runs on Windows and Apple Silicon Macs. The key list has a macOS column, and wiki key tables link to it.

Under the hood: new session/activeCommand.ts and the mode_switch tool; SessionQueue.add takes ordered batches in one transaction with an HTTP batch field; warm-up uses the inherited env for the default macOS account; usage layout split into usage/layout.ts; new src/script/docLinks.ts, run by prePush, fails on broken links or headings in repo docs and the wiki; leftover upstream GitHub tooling and translation files removed; build notes rotated to archive17.
