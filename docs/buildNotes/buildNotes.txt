macOS dev setup:
The Mac build machine already had the pinned Bun 1.4.2 and the other build tools (PowerShell 7, git, tar), and they are now on PATH for one-off ssh commands too, so the Mac dev notes no longer ask for a manual PATH export. The PATH addition lives in the Mac's ~/.zshenv and only applies to bare non-interactive shells, so terminal shells and scripts started from them keep their own PATH.

Under the hood: docs/dev/macos.md lists the Mac build toolchain. Checks: a plain ssh command on the Mac resolves bun, pwsh, git, node, brew, wezterm, rsync, and tar; a login shell and a script started from it resolve the same tools as before; bun install in the Mac mirror reported no changes. No build ran.
