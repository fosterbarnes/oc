oc palette:
The ctrl+o (cmd+o on Mac) oc commands palette is regrouped by job: Session, Claude, Subagents, Defaults, Updates, Prompt, Appearance, Sidebar, Folders, Server and processes, Tools, About. Groups and the commands inside them are ordered by how often they are used instead of alphabetically, so New session, Notices, Claude account switching, and Show usage sit at the top. command_palette.order still reorders commands inside a group and wins over the built-in order.

Under the hood: command-palette.tsx ranks oc groups (_GROUP_RANK) and commands by name (_COMMAND_RANK); unlisted commands (per-account warm-ups, per-app updates, new entries) go last in their group A-Z. Retired groups: Beta, Layout, Links, Processes, Server, Third party harness management, Third party updates, Tools (experimental). Tests that named the old headings were updated; FORK.md, the wiki, and the oc-palette-entry skill name the new groups. Checks: a probe of the real sort matched the planned order and kept user order first; commandPalette, claudeWarmup, claudeWarmupRendered, and usagePalette tests 32 pass; tui typecheck clean. The live pane test (tuiPane.test.ts) was not run.
