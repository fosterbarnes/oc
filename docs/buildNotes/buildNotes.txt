v0.2.390 fawstaLily [feat. > global Team API account; fix > chat cost]

Team API as a global Claude account:
Switch Claude account now lists your API-credit account (e.g. "Team API") next to your logins; picking it asks once, then every new chat bills API credits until you switch back or the credit runs out. A login that refuses only one model (like a model needing extra usage your org turned off) is no longer marked out of usage for everything; only that model skips it. The wiki's API credit section now covers every place the key can be used.

Real Claude chat cost:
The sidebar's "spent", the prompt bar cost and the subagent footer now show what Claude Code says a reply cost, including every tool step, not only the last one. Costs under a dollar show up to 4 decimals (for example $0.0044) instead of $0.00.

New chat directory line:
A new chat's first message no longer runs into the "Working directory initialized" line, so Claude no longer looks for a folder like `octest` that doesn't exist.

Under the hood: accounts.ts `setCurrentAccount`/`nextUsableAccount` accept the API id; new `modelLimited` map (`account|model`), `markModelLimited`, and a `model` filter on `failoverCandidates`. turnStream.ts `queueAccountSwitch` marks only `account|model` when a rejection has no `rateLimitType` (a Fable 5.2 `org_level_disabled` rejection had marked all logins limited for 12 days). tui claudeCommands.tsx global switch lists the API row with a confirm. turnStats.ts `turnCostFromTotal` takes the per-turn difference of the CLI's cumulative `total_cost_usd` (keyed by Claude session id, restored on `--resume`); turnStream.ts puts `turnCostUsd` in finish metadata and session.ts `getUsage` prefers it over the token price. tui util/format.ts `formatUsd` replaces three `Intl.NumberFormat` copies. messageBuilder.ts `getClaudeUserMessage` ends each text block followed by another block with `\n\n`. FORK.md rows updated.

Known limits: a turn with no `result` is still estimated from tokens and its spend lands in the next turn's difference; a chat rolled to API by a model gate asks again each turn under `ask`. The live `account-pool.json` still holds the bogus 2026-12-01 marks until each login is picked once.
