v0.2.379 outcheaWhispering [fix > push auto-delete noise]

push sessions:
Ending a push no longer adds a "not set to auto-delete" line to the agent's report. oc now decides auto-delete on its own: a session started by a push command is flagged once its commit reaches the upstream branch and the push command is still its only prompt. The agent no longer passes anything, so it stops second-guessing the flag. This also fixes a pushed session you kept working in: its old flag stayed set, so it could be deleted along with the later work once the agent finished; a later completion now clears the flag and the session stays.

Under the hood: session_complete has no autoDelete parameter (old callers that still pass it are ignored) and always replies "Marked the current session complete." Checks: task.test.ts 45 pass, including a new session_complete case for not pushed, pushed, prompted again, and non-push sessions; typecheck clean in opencode and tui. The deletion itself was not tried in a live TUI.
