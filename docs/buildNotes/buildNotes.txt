claude code chats:
After switching mid-chat to /spit, or any command that limits file edits, Claude is now told which oc tools replace its own Write, Edit and Bash. Before, it could reuse its built-in Write from earlier in the chat, get refused because that tool was turned off, and give up instead of writing the plan file.

Under the hood: new replacedToolsTurnNote in provider/claude-code/prompts.ts shares its wording with the system prompt line. planSpawn returns the note when tools are replaced, turnStream stores it on the spawned process, and the first message on that process appends it as the last text block (tool_result blocks stay first), then clears it. A command switch already forces a respawn, so the note lands on exactly that turn. New test replacedToolsNote.test.ts checks the note reaches the first message only and fails with the append disabled.
