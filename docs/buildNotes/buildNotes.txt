v0.2.298 mortadellaBoners [perf. > ocSetup parallel installs]

oc dependencies window:
The dependency list appears right away and each row fills in its status as its check finishes, with animated dots while it checks. Missing apps are recognized without starting PowerShell, so the list finishes much sooner on a new PC.

Every download starts as soon as you click Install, and installs that do not conflict run at the same time while admin prompts still appear one at a time. A full install of all 11 rows on a fresh VM went from 680 s to about 2 minutes. Cursor CLI installs faster because its download no longer runs with the slow PowerShell progress bar.

Codex (ChatGPT) desktop now installs with an admin prompt like Claude desktop instead of failing, and it no longer shows "outdated" right after installing: it compares against the version that can actually be downloaded. Claude Code CLI installs through npm instead of Anthropic's install script, whose download server failed on test runs. Downloads retry when a site rate-limits them, and a failing vendor script is retried once and shows its real error.

The summary appears a few seconds after the last row instead of hanging, and a temp download that cannot be deleted yet (the 930 MB ChatGPT installer) is removed in the background. The window is taller so every row fits, stutters less during installs, and opens oc with a fresh PATH. If it crashes, the error box points at ocSetup-error.log in your temp folder.

setup:
The setup no longer ships Cursor runtime test files.

Under the hood: downloads run ahead of each install turn (prepare/install split for the PowerShell 7, Claude, ChatGPT, and Cursor update scripts), and a lock-based scheduler (admin, user PATH, npm) starts any row whose download and needs are ready. Run cleanup waits 2 s, then hands a held folder to a hidden PowerShell started with Start-Process, because a Bun detached spawn of powershell.exe exits without running. ChatGPT's latest version comes from the download's own metadata header instead of the Store feed. The temporary VM debug logging is removed. Checks: dependencies and desktopUpdate tests (38 pass), tui and opencode typecheck, buildCompanion with 0 warnings and errors, live check of the held-file cleanup, and VM runs 2 through 7 (run 7: all 11 rows installed, summary 3.2 s after the last row, temp folder removed). build.ps1 -Release still fails at the release zip step (zip not found, known); the installer does not use the zips.
