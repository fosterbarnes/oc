subagents:
A new "Session subagents" menu switches subagents on or off for the current chat only. Open it from the oc palette, with /sessionSub, or with the new Subagents button in the sidebar under oc Palette. Each subagent has a checkbox, and an "All subagents" row removes the task tool from that chat entirely. Agent files and config are not touched.

Switched-off subagents drop out of the list the model sees and their calls are refused. Naming an agent yourself with @agent still runs it. The sidebar button shows how many subagents are off in the chat. A Claude Code chat keeps its old list until its Claude process restarts, but calls to switched-off subagents are still refused.

Under the hood: the switched-off names live in the session's metadata as disabledSubagents and become task deny rules on each turn (disabledSubagentRules), because session permission rules can only be added to, so a subagent could never be switched back on. The task tool's agent list now also respects session rules (it only checked the agent's own permissions before), and the Claude Code task description comes from the turn's own tool list. Toggling also drops names of agents deleted since they were switched off. Checks run: opencode and tui typecheck clean; tool registry tests 19 pass, including a new one for a switched-off subagent. No TUI dialog test, no Claude fake-model scenario, not checked live in the TUI.
