themes:
oc now defaults to the bundled drac theme, while opencode.exe defaults to the stock opencode theme. Each keeps its own saved theme choice. The oc command palette includes "Switch opencode theme" to change opencode.exe's selection without previewing it in oc.

Settings saved by oc and opencode.exe now merge into the shared settings file under its lock, preserving keys written by the other process. Fork and wiki documentation describe the separate theme settings; the wiki push remains user-driven.

Under the hood: Added theme persistence coverage for separate selections and shared-file key merging. The targeted theme persistence tests and prePush checks passed.
