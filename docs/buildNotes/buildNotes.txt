agent tools, shell, config:
Patches and edits are stricter and clearer: bad patches fail with a precise error, CRLF and mixed line-ending files keep their endings, and two edits to one file can no longer overwrite each other. Grep and glob say when a path does not exist, stop after 30 seconds, and grep reports matches it skipped on very long lines. A command that leaves a background process holding its output no longer hangs the shell tool, and commands killed by a signal say so. `!` shell commands start faster but no longer load .bashrc/.zshrc, so aliases from those files are not available there. An unreachable config URL or a missing {file:...} reference now logs a warning instead of breaking startup. Undo restores renamed files, and the nearest project's skills win over ones from parent folders.
