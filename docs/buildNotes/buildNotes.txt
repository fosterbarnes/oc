terminal font:
The oc palette Font command (/font) now picks a monospace font family, weight, and size for the WezTerm window. oc remembers the choice and restores it on startup. Reset returns the window to the terminal default, including from tabs opened before another tab changed the font. This requires the oc_font Lua handler documented in docs/wezterm.md; other terminals show a warning.

Font Size opens with the saved size ready to edit. Up and Down adjust it by 1 within 4 to 48 pt, with visible arrow hints beside Enter; typed decimals still work. Enter applies the size and Esc cancels. The Font menu also offers half-point size steps.

Under the hood: font discovery reads WezTerm's system font list and font-file fixed-pitch metadata, caches the available families, and sends settings through the oc_font user variable. Updated FORK.md and WezTerm documentation, and rotated buildNotes history into archive12. Recorded checks passed: terminalFont.test.ts (3 tests, 8 assertions), dialog-prompt.test.tsx (7 tests, 26 assertions), TUI typecheck, and git diff --check. prePush runs on this push. Live WezTerm font application remains unverified.
