ocSetup:
The dependency list has a "Select all" box under the column icons. It ticks every row that can be installed and every desktop shortcut box that can be ticked, and clicking it again clears them. It shows a dash when only some boxes are ticked, required rows stay ticked when it is cleared, and it is greyed out while the list is checking or an install runs.

Under the hood: the header icons and the new box share one ListHeader panel. Installs are ticked before shortcuts because a missing row's shortcut box only opens once its install box is ticked. The box syncs through RefreshButtons and uses Click, so syncing it does not re-trigger selection. The shared checkbox template gained a dash mark for the partly checked state.
