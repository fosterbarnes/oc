v0.2.288 sendWallaby [patch > numbered subagent labels]

prompt footer:
When several running subagents share a name, the footer now numbers them, like "Subagent-1 2%, Subagent-2 3%, Subagent-3 4%", instead of repeating the same name. The oldest gets -1, the newest is still listed first, and entries are separated by commas instead of dots. Names that appear once stay as they are, and a lone subagent still gets the detailed line. Numbers count only the subagents running right now, so they can shift when one finishes.

Under the hood: new numberDuplicateLabels helper in tui util/session.ts; subagentUsage in prompt/index.tsx sorts oldest first, drops entries without a context percent before numbering, then reverses. Checks: bun test tui contextUsage (7/7). The push runs prePush.
