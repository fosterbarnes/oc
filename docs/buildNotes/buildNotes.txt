v0.2.206 bindNew

chat window:
Fixed the chat freezing on "esc interrupt" after a Claude turn. The sidebar's plugin list kept rebuilding itself in the background until the screen crashed, which also blocked "Revert whole turn" and other clicks.

cursor:
On Windows, Cursor models now run shell commands on the first try instead of being refused twice. A command that runs past Cursor's time limit is stopped and reported as timed out.

claude accounts:
If CLAUDE_CONFIG_DIR is set when oc starts, that folder is the default account, and a ~/.claude entry in the accounts list now counts as its own account instead of silently merging into it. The Claude warm-up check accepts the extra safety field newer Claude CLI versions send; any other new field still fails it.

logs:
Sending a message no longer writes a harmless "invalid user message before save" error to the log.

code structure:
No intended behavior change: large fork files were split into smaller ones by topic, and oc's own session-title, auto-rename, session-mark and queue/resume code moved out of files shared with upstream OpenCode, making upstream merges easier. This covers the oc config (resident server, revive host, WezTerm), the TUI app palette entries, sidebar tools and usage, Claude warm-up and turn streaming, the Cursor protocol tools and reply reader, and the /btw side question.

Under the hood: Cursor's reply pump is now a CursorPump class. Stale pane tests were updated, a new pane test opens the sidebar files, scripts and usage menus, and pane debug writes were removed. Typecheck, the targeted Claude, Cursor, prompt and TUI tests, and prePush checks passed.
