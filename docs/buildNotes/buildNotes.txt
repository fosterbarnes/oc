v0.2.275 portablySucking

image paste preview:
Pasting an image no longer opens the preview dialog by default. Clicking an [Image N] chip in the prompt opens the preview for that image. "Enable image paste preview" in ctrl+o (/imagePreview) brings back the preview on every paste.

Under the hood: new IMAGE_PASTE_PREVIEW_KEY (image_paste_preview_enabled, default false) in prompt/part.ts gates DialogImagePreview in pasteAttachment. New palette entry oc.image_paste_preview in ocCommands.tsx. The textarea's onMouseUp maps the clicked cell to a text offset with the new offsetAtCell helper, finds the prompt part extmark there, and previews the image file part from its data url (non-data urls are skipped). Hit-testing works per cell, so chips split across wrapped rows still match. Checks already recorded in buildNotes.md: pastedChip.test.ts 6 pass 0 fail (3 new); tui typecheck exit 0. Live click was not tested. The push runs prePush.
