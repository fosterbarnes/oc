v0.2.385 palkiaSpeedrun [fix > Mac test failures and cancel races]

Mac test failures and cancel races:
Pressing Esc and resending quickly, or cancelling while a prompt waits behind a ! shell command, no longer fails with "Session is running in another oc process": the new run now waits for the cancelled one to release the session lock. Cancelling a shell that failed before it started no longer hangs. run_after_turn with a .ps1 script now runs it through pwsh on macOS and Linux instead of failing. Every Mac test failure was fixed at its cause, and the docs no longer keep a list of accepted failures.

Under the hood: session/run-state.ts owned() wraps the cross-process flock in a per-session in-process Semaphore (Runner cancel goes Idle before the old run's finalizers release the flock); new SessionRunState.phase(sessionID). effect/runner.ts stopShell races ready against the shell fiber. core launchDetached sends .ps1 to cmd.exe only on win32, else pwsh -NoProfile -File. claude-code describeSpawnCwd has no default params (an explicit undefined pulled in a process-wide directory) and shares one decision, runtimeStatus.decideSpawnCwd, with resolveSpawnCwdFrom. tui gitBash uses path.win32. Test fixes: core pty replay/detach, Mac keybind expectations, cursor agentUrl fetch stub, sessionTab host paths, startup launcher parse path length, warm-up listener clock stepping in lockstep with the loop, queued-behind-shell wait on the runner phase. New tests: session/run-state.test.ts and a runner cancel test. Bun 1.4.2 applies the preload's 30 s default timeout only to the first file of a run, so whole-suite runs need --timeout 30000; AGENTS.md and docs/dev/testing.md updated, known-failures sections removed.

Checks: bun run typecheck 16/16 clean. core 1079 pass 0 fail, tui 796 pass 0 fail, schema 15 pass 0 fail. opencode full suite with --timeout 30000, six runs: 0, 0, 1 (warm-up listener, since fixed), 1 (startup launcher, since fixed), 2, 0 fail. The two in the 2-fail run (handoff child kickoff failure, v2 pty websocket lifecycle) are unreproduced one-offs: they pass alone and 6/6 under full CPU load, recorded in build notes. Each fixed test failed before (where reproducible) and passes 3/3 after; warm-up listener 10/10 under full CPU load. Not run: Windows PC tests (listed in build notes for the user).
