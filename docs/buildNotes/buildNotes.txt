claude sessions:
Claude provider warnings show as toasts and reach the plugin log without crashing the operation that triggered them. Pressing Esc releases the old turn before the next turn attaches, preventing stale listeners from hanging subagent calls.

queued messages:
Commands, attachments, and messages with different model or agent settings end the running Claude turn after its current tools finish, then run under their own settings. Deleting a queued message lets the current turn continue.

Under the hood: Preserved the SDK toast method binding, wrote log records before surfacing warnings, bounded aborted-turn grace periods, and added turn-listener ownership and tool-boundary preemption.
