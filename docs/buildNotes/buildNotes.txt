v0.2.338 dalkErdtree [feat. > Mac PowerShell update; fix > dialog paste]

third party updates:
On macOS, "Update all" now also updates PowerShell 7, and a new "Update PowerShell" palette entry does it alone. oc updates PowerShell the way it was installed: Microsoft's installer (after the Mac password prompt, with the package's Microsoft signature and notarization checked first), Homebrew (brew upgrade powershell), or the .NET tool (dotnet tool update). A tar.gz archive or an unknown install is checked but not touched and shows under "Update by hand" in the summary.

paste:
Ctrl+V (Cmd+V on Mac) now pastes text into the command palette search, dialog text boxes, and question and permission replies. Before, only the main prompt accepted it.

jev:
New oc palette entry "Jev key" (also /jevKey) saves, replaces, or clears your TypeSafe key, and the jev tools turn on without restarting oc. A missing Jev key no longer shows a warning toast when Claude Code lists jev tools.

Under the hood: new pwshUpdateMac.ts with per-method detection (real path of pwsh plus the com.microsoft.powershell package receipt) and an "update by hand" result; editorPaste.ts adds a low-priority global paste layer for focused text editors; jevClient reads the key from auth.json when TYPESAFE_API_KEY is unset. Checks: tui typecheck clean; pwshUpdateMac, pwshUpdate, and updateProgress tests 20 pass, with a live check on this Mac reporting 7.6.5 -> 7.6.9 (the install itself was not run); full tui suite 801 pass, 3 fail in files this change does not touch, one of them (Git Bash path) failing before it too; tui cli/keymap/component tests 231 pass; jevClient, skillHint, and proxyOpencodeTools tests 9 pass; opencode typecheck clean.
