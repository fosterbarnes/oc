github issues:
The feature request form on GitHub is now written for oc instead of upstream OpenCode. It asks for the problem you hit and the change you want as separate fields, plus an optional area of oc, any workaround you use today, and your oc version. A required checkbox asks you to search existing issues and check SCOPE.md (linked) for things already declined or planned. The emoji name and forced "[FEATURE]:" title prefix are gone.

The FAQ link on the new issue page now opens the wiki FAQ; it pointed at a README section that no longer exists.

Under the hood: feature-request.yml follows bug-report.yml's style with stable field ids; its Area dropdown mirrors the FORK.md section names and needs updating if those are renamed. Checks: both templates parse as YAML (PyYAML). GitHub's rendering of the form was not checked, since it only validates server-side. The push runs prePush.
