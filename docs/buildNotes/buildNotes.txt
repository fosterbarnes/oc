v0.2.378 layneCleo [feat. > slash aliases; fix > slash menu top pick]

slash menu:
Typing /push now puts /agent-push first: command files can list aliases in their frontmatter (aliases: [push]), and an exact alias ranks right after an exact command name. The menu also remembers what you picked for the text you typed, so /re keeps offering /revive even after an undo makes /redo appear. And the highlighted entry no longer silently switches to a different command when the menu's rows change while you type nothing new (late command loading, /redo enabling): it stays on the same command. Aliases work through the menu only; /push followed by text sent without picking from the menu is not a command.

Under the hood: new optional aliases on the command config schema, Command.Info, and GET /command (SDK types regenerated). The TUI ranks exact name, exact alias, the last pick for this query (kv slash.picks, capped at 200, ignored if it no longer matches), then fuzzy order. Checks: autocomplete tests 4 pass, including new alias, pick, and cap cases; typecheck clean in tui, opencode, and core; opencode command and config tests 129 pass; the command loader returned aliases ["push"] for agent-push. The sticky highlight was not tried in a live TUI.
