v0.2.190 trailDepressing

tools:
GPT models are now told that adding a file with apply_patch over an existing one replaces it, so they stop second-guessing whole-file rewrites.

system prompt:
Open-weight GPT models (gpt-oss) are no longer told to use a patch tool they do not have. They get the standard prompt that matches their edit and write tools.

Under the hood: added Patch.usesApplyPatch(modelID) in the patch module; the tool registry filter and the GPT system prompt branch both use it, so tools and prompt read the same model id. Added a system.test.ts case covering gpt-5/gpt-5-codex versus gpt-oss prompts. system.test.ts and tool/registry.test.ts passed (25 tests), tsc was clean for the touched files, and prePush passed. bun.lock and packages/opencode/package.json carry line-ending changes only.
