v0.2.346 ggBigspin [scripts > LF line endings and no README stamping]

line endings:
Files in the repo now use LF line endings on every OS. The push step no longer converts files to CRLF, and the shell scripts and git hooks that broke on the Mac when they had CRLF now work everywhere without a list of exceptions.

README:
A push no longer rewrites the README. The line-count table and scc.txt are gone, and the version line is now a fixed link to the latest release. Pushing no longer needs scc installed, and the oc Dependency Installer no longer offers it.

agent docs:
AGENTS.md is about half its size. The commit-message, testing, agent-test, and debug rules moved unchanged into docs/dev (commitMessage.md, testing.md, agentTest.md, debugRuns.md) and are read only when that work comes up. The build notes summary is about a sixth of its size and now has a size budget; the full old text stays in git history and the archives.

Under the hood: removed setLineEndings, countCode.ps1, readmeVersion.ps1, and the lineEndings script test; agentPush -Context points at docs/dev/commitMessage.md. Checks: no file reports CRLF after the one-time conversion, every moved AGENTS.md line matched HEAD byte for byte, commitSubject and testRunner script tests passed, push.ps1 -DryRun and agentPush.ps1 -Context printed correctly, tui typecheck was clean, and tui dependencies.test.ts passed 18. Known Mac-only failures on unchanged code: buildNotesChanged and installDir script tests and the dependencies.test.ts "finds Git Bash" case.
