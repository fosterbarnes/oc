v0.2.324 twigWhistlin [fix > palette order, gh; feat. > Claude accounts]

Command palette:
Ctrl+P and Ctrl+O now list commands in the same order every time, and rows no longer reshuffle while a reply streams. The palette used the keymap's layer order (newest first), so every re-registration moved whole groups to the top; it now sorts on its own: categories in a fixed order (Session, Prompt, Agent, Provider, Workspace, VCS, oc, System, then others A-Z), commands A-Z inside each, with command_palette.order still pinning commands first. The highlighted command stays the one you picked when the list updates, so Enter runs what you see, and hovering a Suggested copy highlights only that row (also fixes Favorites/Recent copies in the model dialog). Opening the palette no longer rebuilds the app commands when the Claude warm-up status is unchanged, and the session sidebar no longer re-registers its commands on every message update.

Claude accounts:
New palette entry Claude accounts (/claude-accounts) lists every Claude login with email, plan, and usage limit. You can add an account (makes the next ~/.claudeN folder, links the shared Claude files, signs it in), rename, sign in again, sign out, or remove it from the pool. Unnamed accounts now show as claude1, claude2, ... instead of .claude, .claude2. Adding or removing an account reloads oc's config, like changing an agent's model.

Agent shells:
gh works in agent shells again: the Windows sign-in launcher always set the XDG dirs, so gh read a missing config and said "not logged in". It now sets only XDG dirs moved off their defaults. Agent shells and the claude child no longer inherit the resident server password. Turn "start on Windows sign-in" off and on again to regenerate the launcher.

Slash commands:
The built-in debug info dialog is now /debugInfo, so /debug always runs the debug command, which now goes through /revive.
