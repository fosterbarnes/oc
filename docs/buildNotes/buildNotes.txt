v0.2.290 organicThugs [feat. > custom sidebar buttons from palettes]

sidebar:
The buttons at the top of the session sidebar are now yours to pick. In the Command Palette (ctrl+p) or the oc Palette (ctrl+o), highlight any entry and press alt+p to add it as a sidebar button; press alt+p again to remove it. Entries already on the sidebar show a diamond marker in the palette. New buttons go at the end of the list.

Right-clicking a sidebar button removes it, which also covers Command Palette and oc Palette since those two never appear in a palette list. "Reset sidebar buttons" in the oc palette (or /sidebarReset) brings back the defaults: Switch Session, Command Palette, oc Palette, and Subagents. The model and reasoning row stays where it is. To reorder buttons, edit sidebar_buttons in tui.jsonc.

Under the hood: new tui config key sidebar_buttons (command names in order; absent means defaults, reset deletes the key so future default changes still apply). sidebarButtons.ts holds the shared toggle and reset logic used by the palette, the sidebar right-click, and the reset entry. The palette gains a palette.toggle_sidebar modal command (keybind palette_toggle_sidebar), the sidebar renders buttons from registered keymap commands and skips names that are not registered yet instead of pruning them, and HeaderButton gains a right-click handler. The Subagents button now dispatches oc.session_subagents. docs/keybinds.md regenerated; FORK.md and the wiki Sidebar and Configuration pages updated.
