v0.2.327 penguinSoulmate [scripts > agentTest without takeover]

agent testing:
/agentTest on oc's own TUI no longer needs you to leave the PC. A new user-level ocTui tool types keys, text, and mouse clicks straight into the native test window's terminal and returns the screen text, so tests run in the background while you keep working. Keys use the plain terminal encoding only; chords that need the kitty keyboard protocol (ctrl+m, ctrl+enter, shift+enter, ctrl+shift+key) are refused with a pointer to the palette title or the ctrl+x leader form. A test run that took 4.5 minutes now takes about a minute.

tester model:
A bake-off on 8 fixed cases, 2 of them traps, picked GPT-6.1 Terra fast at low effort as the default tester. Luna fast low and Haiku 5.5 low also got 8/8 with no wrong PASS. Claude models can run these tests too.

nativeTest.ps1:
-Screen no longer prints trailing blank padding, so a home-screen read drops from about 11 KB to about 1 KB. AGENTS.md's Agent test section now describes the ocTui route, the key limits, which shared settings cases must leave alone, and that a new tool reaches running chats only after an oc server restart.

Under the hood: the tool, its permission, and the tester and /agentTest changes live in the user config, outside this repo. Checks that ran: the Phase 1 gate (8 cases x 3 rounds plus a fresh window, identical verdicts, shared settings unchanged) and the bake-off UI runs (Terra and Luna twice each, Haiku once, every input through ocTui, no failed calls). No repo tests cover these files. Known: "Reload oc config" reloads the tab's launch folder, not the open chat's folder.
