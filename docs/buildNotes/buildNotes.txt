v0.2.359 backhandDoordasher [feat. > settings sync; fix > picker case]

settings:
New palette entry Sync settings (/sync) keeps skills, commands, agents, themes, prompts, instructions, code, and settings the same on all your machines signed in to the same Tailscale account. Every 20 seconds each machine copies the items that changed more recently on another one; deletes carry over too. Everything syncs by default, and each machine can leave out a whole type, folder, single item, or a Windows-only, Mac/Linux-only, or local MCP tag in the same dialog. When two machines changed the same item, the later change wins; the overwritten version is listed in Sync settings and enter restores it. Every file sync changes is backed up, open projects reload once no session is busy, and a half-saved settings file is never read as deleted.

Import no longer uses Tailscale. Export oc settings (/exportSettings, since /export saves the transcript) writes the items you pick to an .ocpack file, and Import oc settings (/import) reads one back, shows what differs, and imports what you pick with backup and Undo last import. Pickers show items as a tree with tri-state rows. Allow import from this machine is gone.

new session:
The New oc session list (cmd+n) starts on the project you are in again, even when the home folder setting is spelled with different capital letters than the real folder.

Under the hood: core util/ocImport.ts became util/ocItems.ts (shared item model, wire form with a home token and redacted secrets, tree and exclusions, guarded apply), plus new util/ocPack.ts and util/ocSync.ts; the resident server's server/importPeer.ts became server/syncPeer.ts. Fixed a picker bug where including one item under an excluded group included its whole branch, and a damaged sync status file no longer stops the sync loop. New core tests cover the exclude tree and the sync decision rules. Checks: core, opencode, and tui typechecks clean; core ocItems and ocSync tests 11 pass; tui palette and slash tests 16 pass; probes with two fake machines in separate processes over localhost (rewrite, secrets, binaries, exclusions, no echo, deletes, edits back, broken jsonc, restore, pack round trip) and a pack of the real config; new session picker probe. Not checked: sync between two installed builds on the real tailnet, the import, export, and sync dialogs live, the idle-gated reload, Windows.
