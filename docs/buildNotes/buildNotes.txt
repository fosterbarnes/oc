v0.2.308 samuelUranus [feat. > native cua-driver tools]

GUI app automation:
Agents can drive Windows apps with oc's own cua tools (cua_windows, cua_launch, cua_observe, cua_act, cua_verify, cua_close, cua_takeover, cua_raw) whenever cua-driver is installed, with no cua-driver MCP server entry. oc starts one cua-driver process for all chats instead of one per project and stops it after 10 idle minutes. The tools take about 8,000 characters of descriptions instead of about 144,000 for the old 61 MCP tools, so non-Claude models send much smaller requests. Each chat and subagent drives with its own cua session and cursor badge, so they no longer disturb each other's reads.

permissions:
A new cua permission lets background input run and asks before an agent takes the foreground, closes an app oc did not launch, uploads or downloads files, reads the clipboard, or captures the whole screen; config, install, and recording commands are blocked. cua_takeover asks once to allow foreground input for a set number of minutes, for when you step away. The permission prompt for these tools says what is being approved. A rule that denies everything except cua (like the /agentTest tester's) now shows the cua tools, and denying cua hides them.

docs:
FORK.md and the wiki describe the built-in cua tools and the CUA_DRIVER_PATH setting.

Under the hood: tool/cuaDriver.ts owns the cua-driver child over MCP stdio (version floor 0.35.2, per-session labels revived when the driver ends them, 120 s call timeout that restarts a stuck driver), tool/cua.ts holds the eight tools and a pure policy function, and Permission.disabled now maps cua_* and jev_* tools to their shared permission key. Checks: new cua policy test and the new permission test pass (cua and permission tests 88 pass); registry, agent, tool-define and permission preset tests 97 pass; opencode and tui typechecks clean. Read-only probes against the installed driver confirmed tool output, diff reads, screenshots, zoom, every permission gate, takeover, session revive and two-session isolation. Live on the installed build: Calculator 6 x 7 = 42 and keyboard 9*9 = 81 through subagents and /agentTest, with the foreground and takeover prompts asking once, no prompt when closing an app oc launched, and one driver process shared by two sessions.
