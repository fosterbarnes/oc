v0.2.303 basementMapper [feat. > ocSetup sections and dev tool rows]

ocSetup:
The dependency window is now called "oc Dependency Installer" (window title, crash message, and Start menu shortcut; upgrading removes the old "oc dependencies" shortcut). Its list is split into three collapsible sections, all open at first: oc Runtime Dependencies (the existing rows), oc Dev. Work Dependencies, and Basic Coding Tools. Each section header has its own Select all box with a partly-checked dash, and clicking the box never opens or closes the section. The single Select all at the top is gone.

New optional rows, none ticked by default: Bun, .NET 10 SDK, .NET 8 and .NET 10 Desktop Runtimes, Inno Setup 6, GitHub CLI, and scc for working on oc, plus Notepad++, GitHub Desktop, and VS Code. Notepad++ and VS Code get a desktop shortcut box; GitHub Desktop makes its own.

The window opens taller (840, capped at the screen height). When the list is taller than the window, a thin flat scroll bar appears to the right of the panel, centered between the panel and the window edge, and disappears when the list fits. After installing with desktop shortcut boxes ticked, the window switches straight to a "Finishing setup" summary while it re-checks apps and makes the shortcuts, instead of sitting on the list; Back and Open oc wait until it reads "Setup complete".

installer:
Uninstalling oc also removes scc.exe when the dependency window put it next to oc.exe.

Under the hood: every engine row carries a section label and the window groups rows by it, keeping each section's open state across the post-install reload. New rows verify their downloads by GitHub digest and/or Authenticode signer; signers were checked on real installers (.NET installers are signed ".NET", the Notepad++ installer "NOTEPAD++", Inno Setup "Pyrsys B.V."). Inno Setup is pinned to the 6.7.3 tag because buildInstaller.ps1 looks for Inno Setup 6, and exe installers that exit 3010 (reboot required) now count as success. Fixed black row text inside the new sections (the system Expander style sets black text). Checks: dependency tests 19 pass, tui typecheck clean, buildCompanion.ps1 with no warnings or errors, the built oc.exe detects every row with its section, and buildInstaller.ps1 builds the setup for the VM. build.ps1 -Release still fails at its release zip step (zip not installed), a known failure that the installer does not use. The new rows, the finishing screen, and the scroll bar have not been run on the VM yet.
