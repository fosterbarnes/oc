v0.2.318 landsSchwangin [fix > Claude shell output blocks]

Claude:
Shell commands that Claude models run (Bash or PowerShell) now show their output in the chat with Expand and Full output, the same block other models get, instead of a single "$ command" line. A Claude command that exits with an error code now shows its output and records the exit code instead of turning into a red error line. Permission denials and interrupted commands still show as errors. While a Claude command is still running its row stays one line, because Claude Code only sends the output when the command finishes.

Under the hood: the Claude Code provider now attaches the command output to each shell result through a new cliResultMeta helper, and treats Claude's "Exit code N" results as finished runs with that exit code, matching oc's own shell tool. Checks: a throwaway fake-Claude probe covered success, an exit-code failure, a denial, a PowerShell failure, and a non-shell tool; opencode typecheck clean; the 19 Claude Code test files that touch tool results pass apart from 4 known failures listed in AGENTS.md; checked by hand in a live TUI with echo hi and exit 3.
