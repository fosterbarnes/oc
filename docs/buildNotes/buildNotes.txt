Claude Code chats:
When Claude is busy, a message you send now reaches it after its current tool call instead of waiting for the whole turn, and is never sent twice. Waiting messages can be edited or deleted until Claude has them, stopping a turn no longer lets unread messages start unattended work, and reverting a delivered message reverts the whole turn it joined. Claude now also answers your first prompt in sessions opened with oc <project>, instead of replying that there was no request.

Command palette:
New "Update all" entry updates Claude Code, Cursor CLI, Codex CLI and, on Windows, the Claude, Cursor and ChatGPT desktop apps in one go, skipping tools that are not installed and asking once for the desktop apps. Desktop app updates no longer fail with an "AuditToString is already present" error when oc runs connected to its background server.

Revive:
Revive no longer aborts after a successful build when Windows has reused an old terminal's process ID.

Under the hood: steering adds a stdin intake to the Claude turn stream, delivery receipts on message parts, and safe busy-time deletion. The loop's pending-message pick now needs a prior Claude step, which fixes the dropped first prompt. The test flow report counts a lower CLI cost counter as a new CLI process. Steering, fake-model, flow-report and updater tests passed, and prePush passed.
