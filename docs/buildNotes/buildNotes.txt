claude warnings:
Claude Code provider warnings and errors now appear as TUI toasts instead of printing over the chat screen. Repeated messages appear at most once a minute, while full details remain in the plugin file log when enabled.

subagent hint:
The view subagents hint now appears only while a reply's subagents are running, including background tasks, and disappears when they finish.

agent workflow:
Agents no longer offer to build, install, and revive oc after changes. Builds and installation remain user-driven.

Under the hood: Moved toast delivery into runtimeStatus, added logger toast and deduplication coverage, and avoided a duplicate conversation-recovery toast. The targeted logger tests and pre-push checks passed.
