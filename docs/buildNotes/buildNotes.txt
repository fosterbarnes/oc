prompt bar:
When a chat has exactly one subagent, the prompt bar now shows a detailed line for it: agent, model, effort, token count, and context use, for example ↳General-gpt-5.6-sol-Low 10.3K (10%). Claude model versions read with a dot (claude-opus-5.5). If the model's context limit is unknown, the line shows tokens without a percent instead of hiding the subagent. With two or more subagents the bar keeps the short "General 10% . Explore 4%" list for now.

Under the hood: contextUsage also returns the model ID and effort of the last assistant reply, and the new formatSubagentUsage in util/session.ts builds the line. Checks run: the TUI contextUsage test file (5 pass, including new formatter cases) and the TUI typecheck. Not checked live in the TUI.
