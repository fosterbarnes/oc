v0.2.387 ummTension [fix > typed command aliases]

Typed command aliases:
A command alias such as `/push` (from `aliases: [push]` frontmatter) now works when typed, not only when picked from the slash menu. Queueing `/push` with Alt+Enter no longer warns "Only server commands can be queued", `/push some notes` sent with the menu closed runs the command with "some notes" as its request, and aliases also work in messages with several commands, revive chains, and queued-prompt edits. When two commands share an alias, the menu and the typed message now pick the same one. `oc run` and ACP editors still need the real name.

Under the hood: tui prompt/slash.ts adds a SlashCommand type and slashNames(), which maps typed names to command names (a real name beats any alias, and a shared alias goes to the first command listed). splitSlashSteps and extractSlashCommands resolve through it and emit real names, so queue entries, session.command, and the server never see an alias. The autocomplete server rows list only the aliases they own under the same rule. Wiki Agents-and-Skills.md updated.

Checks: new alias cases in tui slash.test.ts and part.test.ts (a typed alias resolves; the same alias in a paste or quotes stays text; collision rules); slash, part, and autocomplete tests 24 pass; tui typecheck clean.
