v0.2.352 whitneysNutz [feat. > prompt notices; fix > safe /update]

notices:
Popup messages (toasts) now show right above the prompt box, where you are typing, instead of floating over the top right of the screen. Each one has a colored bar on the left (green success, red error, yellow warning or info), a blank line of space inside at the top and bottom, and its action (such as View details) on the last line; click it to run the action, hover to keep it open. Long messages are cut after six lines; /notices keeps the full text. This works on Home and in sessions; while a dialog is open, messages still float at the top right. The new Notice display setting in ctrl+o (/noticeDisplay) switches between prompt (default) and floating.

updating oc:
/update now refuses to run when the oc source folder has uncommitted changes to tracked files or commits that are not on GitHub main. It lists them and changes nothing; commit and push, or stash, then run it again. Before, it asked and then discarded them, which wiped a day of uncommitted work once. The reset step checks again right before it runs, so changes made after the first check are safe too.

third party updates:
New Update WezTerm entry in ctrl+o, also part of Update all, keeps WezTerm on the latest nightly: the Homebrew wezterm@nightly cask on macOS, the nightly installer after a UAC prompt on Windows. Open WezTerm windows, including the one oc runs in, stay open. Update all and the palette now only list programs installed on this machine; one installed later shows up the next time the palette opens. The Update all summary separates Updated (with old -> new versions) from Up to date, Claude Code, Cursor CLI, and Codex CLI all report the same way, and with Auto confirm updates on each update installs as soon as its check finishes. Progress lines are one line each and wrap to fit.

Under the hood: harnessUpdate.ts is replaced by thirdPartyUpdates.ts, one per-platform target list with local install detection; shared helpers moved into cliUpdate.ts and desktopUpdate.ts. Toasts can be docked by the main prompt (toast.dock()); the floating box hides meanwhile. OcSource.unsafe names what blocks /update and OcSource.reset throws on it. The uncommitted work lost to the earlier /update reset was recovered by replaying the recorded edits and checked against the surviving files. Checks: tui typecheck clean; update progress, CLI update, and WezTerm update tests 32 pass; ocSource tests 5 pass (new refusal test guards the data loss); core typecheck clean. Known: dependencies.test.ts "finds Git Bash from git's cmd folder only" fails on macOS (Windows path test). Live TUI, a real install, and live /update not run.
