v0.2.282 cherrysFritz [patch > prompt bar shows only running subagents]

prompt bar:
Subagent usage in the bar under the prompt now lists only subagents that are still running (busy or retrying). Each one disappears the moment it finishes, fails, or is aborted. A subagent waiting on a permission or question prompt stays visible. With several running, the compact list shrinks to the detailed single line once only one is left.

Under the hood: the subagentUsage memo filters child sessions by session_status (missing counts as idle) before computing context usage. FORK.md and the wiki describe the new behavior. Checks: bun run typecheck in packages/tui; the bar was not live-checked. The push runs prePush.
