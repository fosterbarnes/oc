v0.2.342 willAragorns [perf. > Mac paste; feat. > Mac queue key]

mac paste:
Pasting with Cmd+V on the Mac is faster: an image pastes in a few milliseconds instead of almost a second, and text no longer waits on an image check first. A clipboard that holds both a picture and text (for example cells copied from Numbers) now pastes as text.

claude chats:
After the first message in a chat, oc sends each message to Claude Code right away instead of first looking up tools and skills it did not use.

keys:
On a Mac, Cmd+Option+Q queues a prompt while the session is busy, and on Home it sends the prompt and stays there. Option+Q still works; plain Cmd+Q still quits the terminal.

Under the hood: the macOS clipboard read now uses OpenTUI's native reader first, with osascript as the fallback (measured 0.81 s down to about 2 ms for a 749 KB PNG). A reused Claude process keeps its own spawn args instead of planning a spawn every turn that was never used (reused-turn pre-send time in fake-model runs: median 5 ms before, 0 after); a probe showed a live CLI does not reload plugin skills, so the per-turn skill refresh was dropped. The mac keybind preset adds super+alt+q to prompt_queue and prompt_submit_background. Checks: tui clipboard.test.ts 10 pass, config.test.tsx 20 pass, tui and opencode typecheck clean; opencode test/provider/claude-code 691 pass, 10 known Mac failures (3 in fakeModel, 6 in steering, 1 in commandPermissions; the last 7 newly recorded in AGENTS.md after failing on unchanged code too).
