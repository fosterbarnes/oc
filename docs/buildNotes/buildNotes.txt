third party updates:
A new Update PowerShell entry (Windows) checks for a newer PowerShell 7 release, asks you to confirm, then installs it after a Windows admin prompt. Open PowerShell windows, including the one oc runs in, are never closed; they keep the old version until reopened, and Windows may ask for a restart to finish. Update all now includes PowerShell, and its single confirm prompt says what each update will do. The palette group is renamed to Third party updates.

Under the hood: the updater reads the machine-wide MSI install from the PowerShellCore registry entry, gets the latest stable version from Microsoft's buildinfo feed, downloads the GitHub MSI with an allowlisted final host and a Microsoft Authenticode signer pin, and runs msiexec elevated with Restart Manager shutdown disabled. The MSI restores its saved install options itself, so none are passed. Versions 7.7 and later are refused because Microsoft ships no MSI for them. Checks run: the new pwshUpdate parser tests (6 pass) and a live check-only run that found 7.6.6 -> 7.6.7. The install step needs a user build and a live run.
