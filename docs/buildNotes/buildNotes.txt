v0.2.233 manipulatedGlaze

notifications:
New Notices entry in the oc palette (/notices) lists every toast since oc started, newest first, with its time; enter opens one in full. Warning and error toasts end with "/notices to read again", so a message that vanished can be found.

Any model's unanswered question now gets one "Question waiting" toast after 5 minutes, naming the session, when you are looking at a different session. With attention enabled in tui.json, a desktop notification and sound also fire when the terminal is not focused. This replaces the Claude-only "proxy call still waiting" toast, which looked like an error.

claude code:
Internal Claude Code warnings no longer pop up as raw toasts; they are written to opencode.log with channel=claude-code like everything else. Claude Code still tells you in plain English when an agent names a model or reasoning effort it does not have, when proxyTools or proxyOpencodeTools lists an unknown name, or when an image link or unsupported attachment was not sent. The same toast shows at most once a minute. A tool that runs out of time shows as a tool error in the chat instead of a warning toast beforehand.

subagents menu:
Pressing Enter on general or explore in the Subagents menu opens the model picker, then asks for the reasoning level; "Auto" leaves it open so each run can pick. The menu shows the new model once the server reloads. Other subagent rows still copy their name on Enter. The palette "Subagent model" entry saves through the same path.

Under the hood: the question reminder lives in the shared TUI notifications plugin (feature-plugins/system/notifications.ts), so it is provider-neutral. The Claude logger mirrors warn/error through a ManagedRuntime over Observability.layer with the shared memoMap; the proxy broker's stall and deadline lines are NOTICE records in plugin.log only. The toast history is kept in ToastContext (last 100 per TUI run). DialogSubagents refetches agents on sync.configReloadEpoch; persistAgentModel takes an optional variant, and an empty agent variant is removed from config. Plan: docs/dev/noticesPlan.md.
