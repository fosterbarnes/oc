v0.2.383 guwopQld [feat. > rename_file tool for plans]

rename plans:
/spit and /spitS can now rename a plan file in its own folder, for example ocSourceBeam.md to ocMirror.md. The rename only works where the mode could already write, never overwrites another file, and cannot move a file to another folder.

Under the hood: new tool rename_file (tool/renameFile.ts + .txt) takes filePath and a bare newName, so it renames in place by input shape. It rejects path separators, dot names, the same name, and ":" on Windows; asks edit permission for both the old and new path; and inside withFileLocks([from, to]) refuses a missing source, a directory, or an existing destination (except a case-only rename of the same file). It publishes watcher unlink/add and FileSystem edited events. permission disabled() makes rename_file follow the edit rule (no own permission key); registered after write in tool/registry.ts. The /spit and /spitS command rules (user config, not in repo) now point at rename_file. Checks: renameFile tests 5 pass; registry, permission, and commandPermissions suites 115 pass; tsgo --noEmit clean; a probe of spit's real edit rules allowed plan renames and denied a non-.md target and repo files. Not run: a live /spit rename (needs a rebuilt oc).
