v0.2.297 stacheChamber [patch > ocSetup icon header and tag dots]

oc dependencies window:
The install and desktop shortcut checkboxes sit side by side at the left of each row, with the app name after them, and the window is a little wider with slightly larger text. The column header is now three thin Lucide line icons: a download arrow over the install column, a monitor over the desktop shortcut column, and a checklist over the tag column. Hover any of them for an explanation; they appear together with the list instead of before it.

Required and Default are now small purple dots before the app name: filled for Required, a ring for Default. Hovering a dot names it. Tooltips open after 100 ms instead of the system hover delay, and buttons have slightly rounded corners matching the checkboxes.

wiki:
The install page describes the dots and header icons.

Under the hood: icon shapes live in the new theme/icons.xaml (Lucide, ISC license, copied path data, no package), drawn as 24x24 strokes scaled to 16 px. The tooltip delay is a metadata override in App's static constructor. Rows use fixed 16 px cells instead of shared size groups. buildNotes.md rotated to buildNotes.archive14.md. Checks: XAML files parse as XML and WPF Geometry.Parse reads all three icons. Not run: ocSetup build or the window itself.
