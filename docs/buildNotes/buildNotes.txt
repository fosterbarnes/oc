v0.2.357 wallabySpasm [feat. > Tailscale import and clipboard tool]

import:
New palette entry Import from another oc (/import) finds oc on your other machines signed in to the same Tailscale account and lets you pick which skills, commands, agents, themes, prompts, instructions, tools, and settings to copy. Each item shows whether it is new or changed, whether it runs code, and how many of its paths do not exist on this machine.

New palette toggle Allow import from this machine (oc.json allowImport, off by default) makes this machine answer imports on its Tailscale address only, and only for your own Tailscale account. It turns on and off without a restart.

Paths under the other machine's home folder are rewritten to yours. Sign-ins, sessions, machine-only oc.json settings, .env/.pem/.key files, and inline API keys or tokens are never sent; your own value for a hidden key is kept. Comments in your config files are kept. Import never deletes anything, backs up every file it changes, and Undo last import (or the toast's Undo) restores it.

agents:
Agents can put text on your clipboard with the new clipboard tool when you ask them to copy something. The copy happens on the server even when no oc window shows the session, and the agent is told if it failed. A code fence around the text and trailing newlines are removed. A "Copied" line stays in the chat; click it to copy again. Set the clipboard permission to ask or deny to confirm or block it.
