CLI, sessions, transcript, shell, notices:
oc update works like oc upgrade, oc plug lists, removes, and updates plugins, oc debug paths <name> prints one path, and oc debug profile <pid> captures a CPU profile or heap snapshot of a running oc. Sessions that finished while you were elsewhere show a ● in the session list until opened, and the current session can be deleted from the palette or with /delete. /copy copies the last reply, /copy-all the whole transcript, and alt+up/alt+down jump between messages. Tool rows fill in while the model is still writing the call, read rows show line ranges, and the transcript can switch to grouped or summary views. ctrl+b also moves a running shell command to the background, and shell rows have a Full output view. Plugin or MCP failures pop a toast that opens details and can start an investigation session, release notes show once after an update, and the TUI config reloads when saved.
