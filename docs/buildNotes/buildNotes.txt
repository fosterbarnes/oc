v0.2.263 cinematicSunbathing

stopping subagents:
Pressing Esc on a parent chat now also stops every subagent it started, instead of leaving them running. The new palette entry Stop session subagents (/stopSub) stops the subagents of the current chat (or of its parent, when run inside a subagent) without stopping the parent chat, and all chat history is kept.

claude auto-resume:
Turning Claude auto-resume off now cancels wakes that were already queued, so chats no longer come back on their own at the next usage reset. The off option in the Claude commands now says so. Stopping a chat also drops its own queued wake.

Under the hood: ScheduledResume.setEnabled(false) clears its entries, takeDue clears leftovers while disabled, and fireEntry drops a claimed wake when disabled. New cancelSession(sessionID) drops one session's wake and resume count. SessionPrompt.cancel now cancels child sessions first, then calls cancelSession, then the usual pause, runner and question cancel. Checks run: bun test for scheduledResume.test.ts (23 pass) and tsgo typecheck in opencode and tui. The Esc cascade and /stopSub were not run live; they need a rebuild.
