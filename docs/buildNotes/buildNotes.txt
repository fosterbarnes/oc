v0.2.310 liquidJeff [fix > copy slash-command messages as typed]

session messages:
Copying a message you sent with a slash command, from its Copy action, now copies the command you typed, like /spit fix it, instead of the expanded command text. /copy-all and /export show the typed command for those messages too.

docs:
The wiki Sessions page describes how slash-command messages copy.

Under the hood: the message Copy action reuses promptFromParts, the same path as Edit, Revert and Fork, and no longer throws when a message's parts are not loaded. formatPart in util/transcript.ts writes typedText for text parts, which leaves assistant parts unchanged.
