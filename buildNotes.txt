v0.2.120

claude models:
Claude Haiku 5.5 is now in the Claude Code model list at $0.10/$0.50 per million tokens, labeled 0.1×. Haiku 5.5 bills 5x more once a prompt passes 100K tokens; oc shows only the base price for now, because oc's config does not carry price tiers yet. Claude Sonnet 5 now shows its real price ($2/$10, 2×) instead of $3/$15, and Sonnet 5.5 cache reads now cost $0.10 per million after Anthropic's 2026-10-07 price cut.

update claude code:
The oc section of the command palette has a new "Update Claude Code" command (or /updateClaudeCode). It runs `claude update` for the configured Claude CLI and shows the result in one toast. Chats that are already running keep their current Claude Code process until it restarts; new ones use the update.

claude chats:
Pressing Esc mid-reply and then sending a new message no longer shows the cut-off reply at the start of the next answer. Undoing a message now always rewinds Claude's memory, even when Claude gave the same short reply before and after it; the first undo after installing this build may not rewind a chat saved by an older build. Token counts per turn are now correct (output used to show a handful even for long replies), and a refusal such as a usage limit or bad login appears once instead of twice.

claude test flow:
Every step of claudeTestFlow (instructions, tools, question form, parallel subagents, interrupt, compact, revert, restart, model switch, cache) now runs automatically against a scripted fake Claude model with no login and no tokens. Five on-screen checks drive oc's real TUI in a hidden WezTerm pane to confirm interruption, question answers, todos, compaction, and provider notices. An opt-in real-model run (`.scripts\claudeRealFlow.ps1`) checks your Claude token with one tiny request, saves it encrypted for your Windows account, runs the flow against the real model, and writes a pass/fail report with tokens and estimated cost per step. `-Step7` runs only the model switch and file deletion for a few cents, and `-SwitchModel` picks that model. The flow now defaults to Sonnet 5.5 switching to Haiku 5.5. Usage-limit and login refusals stop the run right away, and missing cost data is marked unavailable instead of free. Real runs passed 22 of 23 checks; the one failure (step 7 file deletion) turned out to be a bug in the test's file check and now passes on Haiku 4.5 and Haiku 5.5. Report files are gitignored.

readme:
The README gained a short day-to-day workflow features list, emoji marks in the session list table, and a much longer writeup on why oc exists, how it differs from native OpenCode, the subscription setup it assumes (Codex, Claude Code, Cursor), and a typical day of model usage. App icons were added under src/.res.

Under the hood: the test server speaks Anthropic's /v1/messages stream with unique tool ids and records unanswered routes. Shared fixtures keep runs off your real profile: temp Claude config, a C:\ocTestTmp root outside the profile for CLAUDE.md checks, a fixture database, blank BASH_ENV, and hostEnv(), which drops inherited CLAUDE*/ANTHROPIC* variables so runs from inside a Claude session behave like a plain shell. The pane checks wrote about 71 test chats into the real oc database, because WezTerm on Windows layers the registry's OPENCODE_DB over each pane; isolation variables now go in the test's own WezTerm config, and a check confirms the chat lands in the test database (the old test chats are still there). Pane cleanup stops only processes it can prove it started, by mux-server creation time, never by bare PID. Exchange hashes now include the exchange's position, oc stores message_delta's final usage instead of message_start's, and the report reads Claude Code's cumulative cost footer as differences. Step 7 now shows each tool's command and result, and the Claude CLI transcript when the check fails. A final pass with Grok 4.6 subagents fixed the update command's output handling, the script's report lookup, a compact pane check that could pass early, and several weak assertions. AGENTS.md records the pane-environment and hostEnv rules. Checks that passed: catalog and bridge tests 37, report checks 6, fake-model scenarios 18, pane checks 8, ACP lifecycle 6 and run-process 13 (shared harness), opencode and tui typecheck. Real-model step 7 passed on Haiku 4.5 and 5.5; a full real flow on the new defaults has not been run.
