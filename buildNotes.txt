repository cleanup:
SCOPE.md now records upstream features oc leaves out, plans for later, and retired features. upstream fixes:
C++ module files get syntax highlighting, Windows plugin names display correctly in /status, and remote configuration login failures explain how to sign in again. Copilot message conversion and streaming, MCP browser handling, npm module resolution under Node, file search, and PTY handling received selected upstream fixes. launcher and revive:
Resident server URLs support IPv6 loopback, occupied ports produce a useful error, and abandoned partial startup locks can recover. Standalone servers and old resident processes leave another server's state record alone. Revive serializes installs, restores the previous binaries if the replacement server fails to start, and includes debug output when reviving ocdebug. WezTerm revive reopens owned oc panes before closing their old panes, preserving unrelated shells and other instances.

Under the hood: removed workspace and test-runner references, retained historical notes in buildNotes.archive9.md, and updated fork and upstream-sync documentation. Checks passed: changed Copilot conversion/model and npm tests; launcher safety, serve-process, oc CLI/config, revive, and session LLM tests; TUI filetype and sidebar tests; and the agent-push pre-push checks. Real-model checks were not run. Remaining upstream parity work, the native upgrade release-source blocker, and lockfile workspace cleanup are recorded in buildNotes.md.
