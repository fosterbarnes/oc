v0.2.109

sidebar plugins:
The sidebar now lists configured third-party server and TUI plugins together, with a version and a badge showing which parts loaded. Failed plugins show their error, and the section opens automatically when there is a failure. Built-in plugins appear as a muted line.

Under the hood: Added `GET /plugin` status endpoint and regenerated the legacy JavaScript SDK. Plugin load status is captured by the server and merged with the TUI plugin list by target. Added the Plugins sidebar section and updated the affected service fakes. Focused tests and package typechecks passed; live TUI check remains.
