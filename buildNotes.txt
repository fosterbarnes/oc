v0.2.137

work directories:
/work copies staged, unstaged, and untracked contents without changing the source checkout or index. /done brings only the copy's changes back into its original parent as unstaged edits, preserving the parent's own work and newer commits. Nested copies return to their recorded parent. Conflicts list affected paths and leave the parent unchanged.

work cleanup:
The copy instance is disposed before its folder is removed. State copies install dependencies when a root package.json exists, with installation failures reported as warnings. Removed temporary work diagnostics and the change-transfer dialog.

git checkouts:
Git operations respect the repository's autocrlf setting, preserving CRLF checkout contents without phantom changes.

Under the hood: added snapshot-based copies and explicit-base merges with temporary indexes, retained parent/base metadata, and regenerated the client variants and legacy SDK for optional copy state. Increased the nested-copy test timeout for sequential Windows Git operations. Targeted Git tests and pre-push checks passed.
