Every version bump now picks a random two-word name from the YapBot word list. The name appears in commit subjects, GitHub release titles, and release download file names.

The bumpVersion script bumps the version and name together; -RerollTag picks only a new name. Release -DryRun previews the title and file names. Version names remain scripts-only.

Under the hood: added cryptographic random word selection and version-tag validation, updated agent-push message validation, and corrected synchronization documentation to reflect version bumps. PowerShell parsing, version-tag format and bump checks, release-asset naming checks, and pre-push checks passed.
