v0.2.105

work session:
Type /work in a session to move the current session into a git worktree next to the repo (for example GitHub\oc.work-<name>), so the agent's edits stay out of your real checkout. If you have uncommitted changes it asks whether to bring them along, the same way the Move session dialog does.

done merge:
Type /done to squash-merge everything from that worktree into your real checkout as staged, uncommitted changes, move the session back, and delete the worktree. It refuses if your real checkout has uncommitted changes to tracked files, and if the merge conflicts it undoes the attempt and keeps the session in the worktree so nothing is lost.

Under the hood: the worktree is detached with no branch to clean up, and the merge snapshots the worktree with low-level git commands that skip commit hooks.
