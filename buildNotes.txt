v0.2.97

command markers:
Command markers are now a native alpha feature, off by default. When enabled, agents can run your preset commands by writing a named marker on its own line, without a tool call. Commands can return output in the reply, open a visible PowerShell window, or run after the turn finishes. The global markers.json file controls the commands and whether permission is required for each one. The command palette includes an on/off switch and shows an alpha warning before enabling the feature.

personal terminal commands:
Added and live-checked personal /zoom-in and /zoom-out commands that change WezTerm text size without an AI reply. These live in personal oc and WezTerm configuration outside this repository; this commit records the completed work.

Under the hood: native marker handling replaces the project-local proof of concept, skips fenced code, deduplicates names, bounds displayed inline output, and logs execution. Configured commands are advertised to native models and Claude Code, and agents must ask before editing the global marker file. The personal zoom plugin check passed with 14 assertions, and scoped review found no actionable defects. Native marker behavior has not been confirmed live.
