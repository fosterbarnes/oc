v0.2.122

sidebar buttons:
Session, model, and reasoning controls now look like buttons. Choose Outline or Minimal from Sidebar button style in the oc command palette, or /sidebarButtonStyle. Outline uses square rectangular borders with left-aligned text. Minimal fits each control on one line with brackets. Hover changes only the text and outline color. Switching applies immediately and saves your choice.

session status:
Sending a prompt automatically marks the session in progress, including reopening completed or failed sessions. The separate agent tool for marking sessions in progress was removed. Session completion is hidden from agents by default; /imp enables it for its own turn, with instructions to mark complete only after the main implementation goal and required checks are finished.

command permissions:
Command files can now enable or disable tools through permission frontmatter using allow or deny. Overrides apply to that command's turn without changing the session's saved permissions.

Under the hood: shared sidebar button rendering replaces duplicated text actions, discarded styles and hover backgrounds were removed, and resolved configuration owns the live style default. TUI setting writes preserve JSONC comments. Command permissions travel on the user message and are merged only for the active turn; noReply prompts leave status unchanged and subagent sessions are excluded from automatic marking.
