v0.2.166 dogsFibber

pasting:
Ctrl+V in oc can now read copied image files and raw image data from the Windows clipboard. In WezTerm, oc marks the active TUI so the terminal configuration can forward Ctrl+V to oc. Plain text uses the native clipboard reader, and copied image files keep their original path.

image attachments:
Prompt images are saved to %LOCALAPPDATA%\oc\images, configurable through attachment.image.save_dir, and the agent receives the saved path alongside the image. Identical images reuse a saved file, and images already on disk use their original file. Models without image input support are directed to the path. The image folder is available to the agent without an external-directory permission prompt. The oc palette now includes Clear saved images with confirmation.

Under the hood: Image bytes are saved before normalization, writes are serialized, and save failures allow the prompt to continue. Non-base64 data URLs are skipped by the save step. The regenerated JavaScript SDK includes save_dir and existing resume and Claude-account route changes. Checks passed: three targeted session prompt tests, eight clipboard tests, and the agent-push pre-push checks. Earlier session verification also passed typechecks in opencode and tui. These changes have not been checked live in the TUI. The companion WezTerm keybinding change lives in its separate repository and is not part of this commit.
