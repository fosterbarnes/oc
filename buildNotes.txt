v0.2.90

rename:
The /rename toast now shows the model that wrote the new title on a second line, as "Model used: provider/model". It names the model that actually succeeded, so you can see when a fallback model stepped in. The "Title unchanged" toast shows it too.

Under the hood: the session.rename endpoint now returns { session, model } instead of the bare session, and the legacy JS SDK types were regenerated. The rename fallback suite passes 14/14 with a new check that the returned model is the one that succeeded, and type checks were clean on the touched files. Full suites were not run.
