v0.2.153 dwellingWassup

slash commands:
Running a new slash command now clearly replaces the previous command's mode, so `/impS` after `/spitS` no longer keeps acting like spitball. On Claude Code turns started by a command with permissions, file tools such as read and edit are available right away instead of looking missing.

session titles:
Automatic and `/rename` titles ignore the slash-command instruction header, so the title follows the actual subject.

Under the hood: `SessionPrompt.command` prefixes the command header and `withoutCommandHeader` strips it for naming; `createProxyMcpServer` takes `alwaysLoad`, set by `planSpawn` only for command-permission spawns; `buildToolEnvironmentNote` has a command-turn variant; the baseline docs, editorconfig, gitattributes, and push scripts were updated, and `syncAndInstall.ps1` was removed. Usage sidebar files were also touched with their freshness test. Checks passed: claude-code provider tests plus rename-digest (one known failure in subagent-hint "proxy defs follow the tools opencode offered the agent", unrelated to this change) and the prompt.test.ts slash composition tests. Live command-permission and TUI checks were not run.
