v0.2.182 fromsoftFreeztyle

subagents:
Added /viewSub to browse and copy subagent names, with model and effort pickers for adding entries and Ctrl+D for deleting entries from the configured writable agent file. Picker handoffs keep the next dialog open. File edits preserve comments, Markdown content, and line endings, and refuse unsupported or unsafe layouts.

agent reload:
Agent Markdown additions, edits, and removals take effect on the next task call. Broken files retain their last working definitions and show a warning. Plugin overrides survive startup and hot reload while untouched fields continue to refresh. The companion /addSub and /rmSub commands distinguish colon-bearing model IDs from effort suffixes and respect explicit names.

revive:
Added /revive-single to build and open native opencode in a new terminal tab while the current oc windows and server keep running. Failed builds leave the installed executable unchanged and wait for Enter. Tab launch failures are reported, and plain-console launches request a visible window. Retired ocdebug, its separate runtime settings, and the old debug build, install, and run entrypoints. The normal installer no longer requires the removed debug artifact.

Under the hood: Added safe subagent-file API operations and regenerated the legacy SDK and Client outputs. Added agent reload, plugin override, file editing, picker handoff, revive launch, and retired-script regression coverage. Corrected a branded model-ID assertion that blocked typechecking and regenerated keybind documentation. Updated fork, scope, script, and project documentation. Checks passed: targeted core, opencode, and TUI regression tests; PowerShell revive cleanup checks; required pre-push checks. Earlier session verification also covered SDK and Client generation and scoped diff checks.
